# KMTableTran
快马客户商品分布表转为商品客户分布表

快马数字 从"销售订单处理"-->待发货-->"客户商品分布" 表导出之后 需要将表格转置
这个表格xls文件是html表格 可以直接用记事本打开
通过WorkBuddy工具提出规则
将这个表格转为 商品客户分布
可以自定义商品名称列宽

格式：
    1. 商品编号列（A列）从商品名称里拆出来，去掉括号，只留编号
    2. 商品名称列（B列）放名称（含装箱信息如 "1箱=12瓶"），列宽可调（默认 100）
    3. "合计"列和各客户明细都写成真正的"数值"，可以求和/合计
    4. 表头行自动换行

列布局：
    A=商品编号   B=商品名称   C=合计   D=合计_数值  E 往后=各客户明细

用法：
    x.py  [列宽]  <输入文件>

示例：
    x.py 1.xls                 # 读 1.xls，输出 1_结果.xlsx，商品名称列宽 = 80
    x.py 120 1.xls             # 读 1.xls，输出 1_结果.xlsx，商品名称列宽 = 120
    x.py --w 120 1.xls         # 同上（命名参数写法）
    x.py                       # 不给参数时，弹提示手动输入文件名

也可以直接把文件拖到 cn.py / cn.exe 上，会自动当成输入文件。
